# Simulações públicas - Sergipe

Esta pasta receberá simulações públicas agregadas de Sergipe.

Cada simulação deve conter:

- premissas;
- seed ou versão reprodutível;
- fontes dos fatos usados como entrada;
- disclaimer;
- limitações;
- recomendações com risco e confiança.

Simulação não é pesquisa de campo e não deve ser apresentada como fato.
