# Como contribuir com pacotes Atlas Sim

Contribuições públicas aceitas:

- state packs e city packs com dados oficiais;
- evidence ledgers com claim, fonte, confiança e limite;
- relatórios markdown reproduzíveis;
- schemas e testes;
- visualizações que não exigem segredo.

Bloqueios:

- chaves, tokens, `.env`, logs e bancos locais;
- caminhos locais;
- persona bruta ou base sintética individual;
- prompts internos;
- número sem fonte;
- simulação sem disclaimer;
- recomendação financeira ou médica conclusiva.

Checklist antes do PR:

- JSON abre sem erro.
- Todo número factual tem fonte e ano.
- Toda inferência tem limite.
- Toda simulação tem disclaimer.
- README e docs foram atualizados.
- Navegador local carrega o pacote.
- Varredura de segurança não encontra marcador sensível.
