# Checklist pré-execução M1 - Sergipe

Use este checklist antes de iniciar, revisar ou publicar o pacote público de Sergipe.

## 1. Escopo

- [ ] Sergipe definido como UF piloto.
- [ ] Nível inicial definido como estadual.
- [ ] Pergunta principal registrada.
- [ ] Período de análise registrado.
- [ ] Domínios incluídos e excluídos registrados.

## 2. Dados e evidência

- [ ] Cada fonte tem nome, URL pública e data de acesso.
- [ ] Fontes oficiais são priorizadas.
- [ ] Indicadores sem fonte são removidos ou marcados como pendentes.
- [ ] Inferências são separadas dos fatos.
- [ ] Limitações de dados estão explícitas.

## 3. Coortes sintéticas

- [ ] Nenhuma persona individual foi publicada.
- [ ] Nenhum texto bruto de agente foi publicado.
- [ ] Pesos dos arquétipos foram revisados.
- [ ] A soma dos pesos foi checada.
- [ ] Limitações da simulação sintética estão declaradas.

## 4. Simulação

- [ ] A simulação tem seed ou versão reprodutível.
- [ ] A simulação tem premissas.
- [ ] A simulação tem disclaimer.
- [ ] Saídas são classificadas como simulação, não fato.
- [ ] Recomendações têm risco e confiança.

## 5. Segurança

- [ ] Não há chave.
- [ ] Não há caminho local.
- [ ] Não há log privado.
- [ ] Não há base bruta.
- [ ] Não há memória operacional.
- [ ] Não há cliente ou caso privado.

## 6. Técnica

- [ ] JSONs abrem sem erro.
- [ ] JSONs validam contra schema quando aplicável.
- [ ] Manifest tem versão e data.
- [ ] Pacotes são carregados sob demanda.
- [ ] O app abre no navegador.
- [ ] Rollback está descrito.

## 7. Publicação

- [ ] Relatório público tem red team.
- [ ] Relatório público tem limites.
- [ ] README ou docs apontam para o pacote.
- [ ] Diferença do commit foi revisada.
- [ ] Varredura final de segurança passou.
- [ ] M1 foi marcado como pronto somente após evidência objetiva.
